# 第五章 钢铁孤岛

我家不大，两室一厅，朝南。客厅的茶几上放着一碗我妈没吃完的苹果，果皮还新鲜，像她只是下楼买个酱油，马上就会回来。

我先进门，把门锁好，挂了防盗链。然后我走到窗边，拉上窗帘，只留一条缝往外看。

楼下没有人。对面的楼，几扇窗户亮着灯，有人影在窗前晃——不知道是在张望，还是在躲。更远一点，城市的方向，一两缕烟升上天空，慢慢变淡。

「你爸妈去哪出差了？」林晓月站在客厅中间，看着墙上那张全家福，声音很轻。

「南边。」我说，「我爸前天走的，我妈昨天去接他，说好一周后回来。」

「他们会回来的。」她说。

我没接话。我走到厨房，拉开冰箱——半包饺子，几个鸡蛋，一截黄瓜，一瓶没喝完的可乐。我数了数，又拉开储物柜：小半袋米，一包挂面，一袋盐，两瓶酱油，一盒还没拆封的饼干。

「东西不多，」我说，「省着吃，够两个人撑三天。」

「三天之后呢？」

「三天之后，我出去找。」

林晓月没再问。她挽起袖子，走进厨房，把那截黄瓜洗了，切片，又把挂面拿出来。她做饭的动作很熟练，开火、倒水、下面，一样一样，井井有条。我站在厨房门口看她，忽然觉得这个画面和窗外的世界隔着整整一个宇宙。

「你家有医药箱吗？」她头也不回地问。

「电视柜下面。」

她找到了医药箱，把里面的东西倒出来：碘伏、棉签、创可贴、一卷纱布、半盒感冒药、一支体温计。她蹲下来，朝我招了招手：「过来。」

我走过去。她拉过我的手——翻墙时划伤的那两道口子，已经凝成暗红色的痂。她用棉签蘸了碘伏，仔仔细细地给我消毒。她的手很稳，一点都没抖。

「你疼吗？」她问。

「不疼。」我说。

「说谎。」她没抬头，「你手都在抖。」

我没说话。她给我缠纱布的时候，我低头看着她，能看见她头顶小小的发旋。洗发水的味道混着碘伏的味道，钻进鼻子里。我的心脏跳得有点快，但这次和害怕没什么关系。

「林晓月，」我说，「今天……谢谢你。」

她抬起头看我，眼睛亮了一下，又低下去：「谢我什么？是你拉我跑的。」

「谢谢你没哭。」我说，「你比我冷静多了。」

「谁说的，」她声音闷闷的，「我在巷子里腿都软了。」

她说完自己也忍不住笑了一下，又飞快地收住。那一刻她看起来又像学校里那个林晓月了——那个我暗恋了两年、却从来没敢说出口的女生。

晚上八点，天彻底黑了。

我们关了所有的灯，窗帘拉得严严实实。我检查了门窗——防盗门两道锁，窗户全部锁死，连厨房的排风扇都拧上了。我把我爸的工具箱搬到客厅，一件一件往外掏：锤子、扳手、老虎钳、一卷铁丝、一把生锈的锯条。最后我打开厨房最底层的抽屉，拿出那把剔骨刀。

刀不长，刀刃磨得很亮。我爸用它剔了十几年骨头，刀柄被手汗浸成了深褐色。

我把刀放在茶几上。刀身映着窗外透进来的一点微光，像一道安静的银色裂缝。

林晓月端着两碗面从厨房出来。面是挂面，清水煮的，上面卧着几片黄瓜，滴了两滴酱油。我们坐在茶几边，一人一碗，谁都没说话，把面吃得干干净净。

「你睡我爸妈那屋，」我说，「我睡客厅。」

「你不睡吗？」

「我守夜。」

她看着我，想说什么，又咽了回去。她走进主卧，在门口停了一下，回头说：「陆沉，你要是困了，就叫我。我睡不着的。」

「嗯。」我说。

她关上门。房间里安静下来。我坐在沙发上，抱着那把剔骨刀，听着楼道里的动静。

一开始什么声音都没有。然后，大约九点多，窗外传来第一声爆炸——不远，闷闷的一声，像有人把一颗雷扔进了城市里。紧接着是警报声，救护车的警笛，一声接一声，又远远地断了。然后是一声惨叫，很近，近得像就在楼下。

我握着刀，手心里全是汗。

十一点，楼下传来一阵拖沓的脚步声。很慢，一步一步，像有什么东西在楼下的花坛里打转。脚步声停了一会儿，又响起来，朝楼道的方向去了。我听见防盗门被什么东西碰了一下——轻轻地，「咚」，像一只手掌按在铁门上。

然后脚步声远了。

我握紧刀，手心几乎要掐出血来。

不知道过了多久，主卧的门开了一条缝。林晓月站在门缝里，声音很小，带着一点鼻音：

「陆沉……我们会死在这里吗？」

「不会。」我说。

她没说话，门缝里的身影站了一会儿，轻轻把门关上了。

我坐在沙发上，把刀放在膝盖上。窗外还有零星的爆炸声，此起彼伏，像一场没有尽头的雷雨。我盯着黑暗里那一点窗帘缝透进来的微光，把「不会」两个字在心里又念了一遍。

我不知道我哪来的底气说这两个字。我只知道，我不能让她怕。

后半夜，我终于撑不住，靠在沙发上睡着了。我梦见赵磊，梦见医务室那张床，梦见赵磊对我张开嘴——他的喉咙里没有声音，只有一个黑漆漆的、望不到底的洞。

我惊醒的时候，天还没亮。窗外灰蒙蒙的，鸟叫了。

林晓月已经醒了。她坐在阳台的椅子上，抱着膝盖，看着窗外。听见我起来，她回过头，脸上还带着压出来的红印子。

「天亮之前，」她说，「楼下又过去了两波。」

「什么？」

「脚步声。」她说，「两波。不是人走路的那个节奏。」

我握着刀，走到窗边，顺着窗帘缝往外看。楼下花坛里，晨雾还没散。小区安安静静，像什么都没发生过。

但那几缕烟，还在城市的方向，慢悠悠地升着。
