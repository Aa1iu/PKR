# 第十章 小队的到来

第十天早上，两声枪响。

我端着刷牙的杯子，站在窗边，听见那两声「砰——砰——」，整个人一下绷紧了。周叔已经摸到窗边，掀开窗帘一条缝，往外看。

小区大门的方向，晨雾还没散尽，有几个人影正在往里走。

四个。穿迷彩服，戴头盔，端着枪。走在最前面那个，个子不高，但步子很稳，枪口始终朝前，每走一步都在观察四周。他们走到小区门口那辆横着的私家车旁边，停下来，蹲下，检查了一下路面。

然后走在前面的那个抬起头，朝我们这边喊：

「有人吗？我们是人民解放军！安全区排查分队！这附近还有活人吗？」

他的声音在空旷的早晨里传出去很远。楼道里响起脚步声，阿凯、陈姐都醒了，趴在窗边往下看。林晓月把窗帘拉开一条缝，攥紧了拳。

「周叔？」我看向他。

周叔把窗帘放下，看着我们，沉默了两秒，说：「是军人。枪是真的，步子也是当兵的步子。开门。」

我跟着周叔下了楼。隔着铁丝网，我们和那四个人互相打量。领头的是个三十多岁的男人，寸头，眉骨很高，眼睛很沉。他身后三个人，一个扛着枪警戒，两个蹲在路边检查地面，动作利落。

「你们是这小区的人？」领头的问。

「是。」周叔说，「我们这里头，七个人，都是干净的。」

「干净？」领头的挑了挑眉。

「干净。」周叔说，「没让那东西碰过，没吐过，体温正常。你要不信，进来查。」

领头的看了周叔一会儿，点了点头：「我姓顾，是排查分队的队长。我们四个，是从东北四十公里外的安全区过来的，任务是把周边小区的幸存者接过去。安全区现在缺人，缺物资，也缺人手。」

他顿了顿，说：「你们要是愿意走，今天下午跟我们一起回去。不愿意，我们不强求。」

周叔拉开铁丝网的口子：「进来说。」

顾队长带着人进来，没有立刻坐下，而是先绕着两栋楼走了一圈。他看了我们钉的木板，看了铁丝网上的菜刀，看了横在车道上的皮卡，回头对周叔说：「老班长，你当过兵？」

「二十年。」周叔说。

「怪不得。」顾队长的表情松动了一点，「这院子守得，像样。」

他在客厅坐下，把安全区的情况跟我们说了。安全区在原武警支队驻地，四周砌了墙，挖了壕，里面已经收拢了上千人。「有电，有医院，有统一的伙食。上头正在组织生产，也正在研究怎么对付那东西。你们去了，能干活，就是安全区的一份子。」

「研究什么？」我问。

顾队长看了我一眼：「你是这儿的学生？」

「嗯。」

「好好学习的那种？」

「……还行。」

他难得地笑了一下：「研究就是研究。武器、药、怎么分辨那东西——你们去了就知道了。现在先不说这个。」

他站起来：「来吧，老班长安排一下，把你们的人集合，我给你们查个体温。查完没问题，收拾东西，下午出发。」

体温筛查是在一楼大厅做的。

顾队长从背囊里拿出一个东西——巴掌大小，白色，像一支粗头的笔，顶端有个小屏幕。他把那东西对准陈姐的手腕，按了一下，「滴」的一声，屏幕上跳出一个数字：36.5。

「体温枪，」顾队长说，「安全区配发的。对着皮肤，一秒钟出数。36度以上，正常；35度以下，有问题。」

陈姐，正常。小悦，36.7，正常。阿凯，36.4，正常。小雯，36.6，正常。周叔，36.2，正常。

轮到我的时候，我把手腕伸过去。「滴」的一声，屏幕上跳出一个数字：36.4。

正常。

我暗暗松了口气。

「老赵呢？」周叔喊了一声。

老赵从角落里站起来，走过来，伸出手腕。顾队长给他测了，36.3，正常。我看了老赵一眼，他低垂着眼，看不出什么表情。他经过我身边的时候，我下意识地吸了一口气——空气里什么味道都没有，只有洗衣粉的味道。

正常。他也正常。

我心里那点没来由的警觉，像被戳破的气泡一样，慢慢散了。

排查结束，七个人，全部正常。顾队长点了点头，说：「你们这院子，干净。收拾东西吧，下午两点出发。」

消息传开，小院子里忙了起来。

陈姐收拾小悦的东西，一件一件叠得整整齐齐。阿凯和小雯把背包塞得满满当当，又拿出来，减半，又塞回去。林晓月蹲在物资室，把贴了标签的箱子打开，重新分配——哪些带走，哪些留下。

「留下什么？」我问。

「留给他。」她朝201的方向努了努嘴。

我走过去。周叔坐在201的门槛上，工兵铲放在脚边，正低头抽一根烟。烟灰落在地上，他没弹。

「周叔，」我说，「你跟我们走吧。」

「我不走。」他说。

「为什么？」

「我六十了。」他抬眼看我，眼里有血丝，「四十公里，走得动，但走得慢。你们带着个孩子，路上不可能照顾一个老人。再说——」他拍了拍门槛，「这院子，我守了六天，守出感情了。你们走了，我在这儿守着。万一你们在安全区待不下去，回来还有个地方能落脚。」

「可是……」

「没有可是。」他打断我，把烟掐灭，站起来，拍了拍我的肩膀，「小子，你听我说。安全区是别人的地方，规矩是别人的规矩。你去了，记住三句话：多看，少说，自己留个心眼。这年头，能信的人不多，能信自己的时候，先信自己。」

他顿了顿，又说：「还有，看好那丫头。她是个好姑娘。」

下午两点，太阳正高。

我们五个人——我、林晓月、陈姐、小悦、阿凯、小雯——背着背包，站在铁丝网门口。周叔站在门里，工兵铲拄着地，像一棵老树。

顾队长带队，走在最前面。他回头看了一眼，对周叔说：「老班长，真不跟我们一起走？」

「不走。」周叔说，「你们走了，我这儿就是这片儿最后一个亮灯的地方。有事，往我这儿跑。」

「行。」顾队长敬了个不标准的礼，「老班长，保重。」

「保重。」周叔说。

我最后看了周叔一眼，他朝我点了点头。我转身，跟着队伍走出了小区门口。

阳光很烈。我们沿着街道往东北方向走，走了大约一百米。路边停着一辆辆被抛弃的车，偶尔有一两个「东西」在远处游荡，顾队长带着人利落地绕开，没有惊动它们。

我走在队伍中间，背着包，心里盘算着四十公里的路程——要过几条街，要绕几片区，要避开几个路口。林晓月走在我旁边，牵着小悦的手，小悦走不动了，她就把她抱起来，颠了颠。

「我来吧。」我说。

「你背包呢。」她说，「我抱得动。」

「那你换着来。」

她没理我，把小悦往上颠了颠，走得稳稳的。阳光照在她脸上，她的侧脸有点红，额角有汗，但脚步没停。

我收回目光。就在这时，顾队长从我身边经过——他要去前面看路况，从我旁边走了过去。

他的脚步很轻。迷彩服在阳光下微微反光。他经过我身边的那一瞬间，我的太阳穴，忽然跳了一下。

很轻。很淡。像一根琴弦被极远的地方轻轻拨了一下。

不是痛。只是跳了一下。就像这几天没睡好，太阳穴里的神经在抗议。

我放慢脚步，看着他的背影。他的背影很普通——寸头，迷彩服，枪背在背上，走路很稳。和任何一个军人没有区别。他在前面停下来，蹲下，看了看路面，回头朝队伍招了招手。

阳光照着他的脸。他的眼神很沉，很平静，和三天前他在铁丝网外打量我们这个院子时，一模一样。

「陆沉？」林晓月的声音在我身边响起来，「怎么了？」

「没事。」我说，「走。」

我加快脚步，跟上队伍。

我走在队伍中间，太阳明晃晃地照着。四十公里外，有一个安全区。那里有墙，有电，有医生，有军队。我背着包，跟着一个让我太阳穴跳了一下的队长，往那个方向走去。

我想起周叔的话：多看，少说，自己留个心眼。

我把那句话说了一遍，又一遍。我的太阳穴没有再跳了。阳光很烈，柏油路晒得发软，队伍在路面上投下长长的影子。

我们一直往东北方向走。

第一卷 完
