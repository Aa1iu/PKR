## 二、恐怖氛围配方

### 1. 「无人可信」公式

1. 让一个角色做出**微小但无法解释**的异常（体温、瞳孔、习惯）。
2. 让主角**注意到但无法确认**（线索的不确定性是恐怖之源）。
3. 让周围的人**合理化**异常（「他就是累了」「你多心了」）。
4. 在读者以为安全时，让异常**具象化**。

### 2. 净化期描写要点

- 声音：呕吐声 + 器官撕裂声，不是血腥而是**湿润**。
- 气味：铁锈味混着腐甜味。
- 视觉：不是血，是**液化后的内脏组织**——便坑里的管状物。
- 生理痛苦让他丧失对外界感知 → 主角「侥幸逃脱」的合理依据。

### 3. 菌毯氛围

- 脚下每一步都可能被记录（[[02-寄生体系详解#五、菌毯系统：行走的监视器]]）。
- 菌毯会「记住」主角——第二次踏入，母体直接知道「他来了」。
- 写脚步时带上「黏腻」的听觉/触觉描写。

### 4. 排查场景紧张感

- 排队、等待、体温枪的读数。
- 主角知道队伍里有寄生体，但不能说——他说出来会被当成疯子（甚至同伙）。
- 这种「知道真相却无法开口」的窒息感，是全书核心张力。

## 三、战斗场景模板

### 第一场战斗（菜鸟 vs 眷属）

1. 目标：便利店门口歪歪扭扭走出的店员（还穿着制服——**熟悉感制造恐怖**）。
2. 武器：垃圾桶盖（临时、笨拙、可信）。
3. 结果：击退而非击杀；主角惊魂未定。
4. 目的：让读者看到主角**毫无战斗力**，为成长留足空间。

### 中期战斗（据点防御战）

1. 利用主场：对小区地形的熟悉是最大优势。
2. 工具：撬棍、消防斧、自制防线（汽车、家具）。
3. 引入兵种差异：撕裂者正面、洞察者侦察、孢子者远程——**像打一场仗，而不是打怪**。

### 终局决战（斩首行动）

1. 多兵种协同：侦察分队引导坐标 → 蜂巢干扰器开路 → 导弹齐射。
2. 代价可视化：战友一个个倒下，不是背景板。
3. 主角的牺牲：为掩护战友被菌丝贯穿腹部——**胜利必须流血**。

## 五、写作纪律与雷区

### 必须遵守

1. **能力不跳级**：主角五阶能力严格对应剧情卷次（[[05-人物设计#二、主角能力体系：五阶进化]]）。
2. **科技不超前**：人类科技树五阶段严格递进（[[03-人类阵营与科技树#四、人类科技发展的五个阶段]]）。
3. **寄生体保留「私心」**：它们珍惜生命，会逃跑、会犹豫——它们不是无脑怪物。
4. **每卷只瓦解一种「信任」**：主题递进，不提前消费。
5. **伏笔记账**：厕所真相（[[06-关键情节设计#一、厕所的真相（贯穿全书的终极悬念）]]）是全书最重要的一笔账。

### 避免雷区

1. 不要把寄生体写成丧尸——它们有战术、有人格、有文明。
2. 不要让主角在第三卷前「开挂」——他靠的是谨慎和主场优势。
3. 不要让林晓月沦为花瓶——她是后勤核心与情感锚点。
4. 不要提前揭示源祖真相——它是第五卷的地基。

- 本设定天然兼容「克系寄生流」「深空异种流」标签。
- 若面向主流平台，可淡化校园背景，改为都市异能/架空世界，加入系统、进化等「金手指」元素。
- 核心竞争力：**「无人可信」的猜疑恐怖 + 外星文明史诗**——前者是钩子，后者是厚度。
