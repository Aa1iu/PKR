# 寄生体系详解

> 它们不是丧尸，而是一支**拥有军衔与后勤的活体军队**。

---

## 一、寄生体系阶级金字塔

```
                ┌─────────────┐
                │   源祖      │  ← 星空深处的文明意识集合体（终局）
                │ (Origin)    │
                └──────┬──────┘
                ┌──────┴──────┐
                │  七位母体   │  ← 全球 7 个，各具性格战略
                │ (女王)      │    见 [[01-世界观与设定总纲#三、七位「女王」：全球战略版图]]
                └──────┬──────┘
                ┌──────┴──────┐
                │   寄生体    │  ← 高阶感染者，文明承载者
                │ (第二级)    │    数量：每母体约 100–300 个
                └──────┬──────┘
                ┌──────┴──────┐
                │   低阶眷属  │  ← 次级孢子感染者，生物工具
                │ (第三级)    │    无独立意识，完全服从指挥
                └─────────────┘
```

---

## 二、第一级：母体

- **诞生**：由陨石碎片直接激活，或在特定条件下由多个始祖级寄生体融合而成。
- **形态**：一座固定的、半生物半矿物的巨型建筑体，深埋地下并向地表延伸触须。**无法移动**。
- **能力**：
  - **繁殖**：孕育「寄生体种子」，通过孢子云、地下水或眷属运输进行远距离投放。
  - **统帅**：蜂巢意识的绝对核心，能跨越大陆范围下达战略指令。
  - **改造**：持续分泌「菌毯」，将周围环境改造成适宜眷属生存的巢穴领域（见 §五）。
- **弱点**：一旦被摧毁，其统治范围内的所有眷属将失去协调，陷入狂暴混乱状态，互相攻击直至死亡。
- **数量**：全球推测不超过 7 个，各自建立「巢穴领域」并可能相互竞争。

---

## 三、第二级：寄生体（高阶感染者）

### 3.1 诞生与形态

- **诞生**：由母体直接生产的「寄生体种子」侵入人体后发育成熟。
- **寄生态**：潜伏于宿主体内，外表与常人无异。体温显著低于正常人类（约 32–34℃），瞳孔在暗处有微弱荧光反应（可自主控制隐藏）。**生理上就是人类**——呼吸、流血、心跳、流汗、流泪（见 [[01-世界观与设定总纲#五、人类为什么无法分辨寄生体？]]）。
- **原始态**：脱离宿主后的真实形态——一团约 40cm 长的灰白色软体组织，表面布满神经束和感知纤毛，**极为脆弱**。

### 3.2 能力

| 能力 | 说明 |
|------|------|
| **宿主更换** | 可主动放弃当前宿体，侵入新目标（详见 §六）。**更换期是最脆弱的时刻** |
| **眷属指挥** | 支配半径 500 米内的低阶眷属，数量上限约 50–100 体 |
| **记忆读取** | 接管宿主后，有限读取宿主近期记忆，用于完美伪装 |
| **集群通讯** | 与其他寄生体之间存在心灵感应（第一层「低语」），范围约 5–10 公里；超出范围需母体中继 |

### 3.3 弱点

- 无法完全伪装体温（近距离接触可察觉异常）。
- 更换宿主时必须暴露原始态。
- **独立意识使其可能产生「私心」**——它们珍惜自己的生命，不会轻易为集群牺牲。这是[[06-关键情节设计#五、寄生体的自我怀疑（后期大伏笔）]]的生理基础。

## 四、第三级：低阶眷属（普通丧尸/怪物）

- **诞生**：由母体或寄生体释放的次级孢子感染人类后形成。
- **智能**：无独立意识，完全服从寄生体或母体的指令；距离母体过远或失去指挥时，进入无差别攻击状态。
- **感染方式**：被撕咬、抓伤或伤口接触孢子；潜伏期短则 30 分钟，长则 6 小时。

### 眷属兵种（功能分化）

| 兵种 | 形态特征 | 职能 |
|------|----------|------|
| **潜影者** | 保留基本人形，无明显外骨骼 | 潜伏、渗透、初期扩散 |
| **撕裂者** | 上肢异化为骨刃或骨锤，胸腔外翻形成骨质护甲 | 正面战斗单位 |
| **洞察者** | 头部膨大，眼耳器官极度发达，四肢退化 | 侦察、追踪单位 |
| **运输者** | 体型臃肿，腹部形成活体货舱 | 搬运物资、转移种子与茧房 |
| **工虫** | 小型，多足 | 修建巢穴、回收尸体 |
| **哺育者** | 触须特化 | 照顾茧房、培育幼体 |
| **掘地者** | 前肢转化为掘进结构 | 建立地下巢穴 |
| **孢子者** | 远程扩散器官 | 远程散播孢子，扩大感染 |

> **写作提示**：将眷属视为「军队兵种」而非「怪物群」来写，尸潮就有了战术与压迫感。工虫/哺育者/掘地者承担后勤，与 [[03-人类阵营与科技树]] 中的人类军事体系形成镜像。

## 五、菌毯系统：行走的监视器

**菌毯不是地板，而是一个巨大的感知与营养器官。**

- **吸收尸体**：分解尸体为营养，反哺母体。
- **运输营养**：构成母体的循环系统。
- **感知震动**：主角踏上去的每一步，都在被监视。
- **记录信息**：菌毯会「记住」曾来过的人——下次踏入，母体立刻知晓「他来了」。

> **氛围写法**：菌毯是氛围神器。进入巢穴领域后，主角每走一步都在向敌人暴露位置，紧张感由此而来。

## 六、宿主更换的代价（关键设定）

宿主更换是强大而脆弱的能力，但有**严格限制**：

1. **每次更换都会丢失部分长期记忆，尤其是情感类记忆。**
2. 更换过频 → 人格破碎 → 沦为只会执行命令的低级存在。
3. 因此，一个能完整保留人格与技能的「原装」宿主**无比珍贵**。
4. 有些高级寄生体**几十年都不会更换身体**。

> **剧情价值**：这个限制使「珍惜宿体」逻辑自洽——寄生体不会随意换人，渗透高价值目标时必须慎之又慎；同时也为主角团队创造了可预测的「换壳窗口」。

### 更换流程

| 阶段 | 过程 |
|------|------|
| **潜伏** | 寄生体接近目标，释放麻醉性孢子使其昏迷或意识模糊 |
| **剥离** | 以原始态从旧宿体口部、眼窝或胸腔裂缝钻出；旧宿体塌缩成一具空皮囊 |
| **侵入** | 原始态通过口、鼻、耳或伤口进入新宿体 |
| **茧房期（1–3 小时）** | 新旧宿体被菌丝连接，形成肉茧。寄生体正在重塑新宿体的神经网络，**完全无力自保**，需眷属守护 |
| **新生** | 新宿体「苏醒」，寄生完成 |

### 更换条件

1. 当前宿体受到严重损伤，无法继续使用。
2. 需要渗透高价值目标（如人类指挥官）。
3. 母体下达战略渗透指令。

## 七、感染与潜伏的完整流程

### 普通感染（→ 低阶眷属）

| 阶段 | 症状 |
|------|------|
| 潜伏期（30 分钟–6 小时） | 初期发热、眩晕（常被误诊为感冒/中暑） |
| 中期 | 意识模糊、瞳孔涣散 |
| 末期 | 剧烈抽搐后完成转化 |

### 寄生体种子侵入（→ 成为寄生体宿主）

| 阶段 | 症状 |
|------|------|
| 潜伏期（2–24 小时） | 几乎无症状，仅有轻微体温下降 |
| 成熟期 | 突发「癫痫」，进入**「净化期」**——排出宿主体内所有脏器，由寄生体组织完全填充 |

> **净化期是全书最具冲击力的画面**：宿主剧烈呕吐，将体内所有脏器液化后作为菌毯养料排出，成为一具中空的「皮囊」。[[06-关键情节设计#一、厕所的真相（贯穿全书的终极悬念）]]即发生于此阶段。

## 八、进阶设定（备用）

- **寄生体之间的竞争**：不同母体出身的寄生体可能相互敌对，争夺资源和宿主。
- **寄生体寿命**：单个寄生体可在宿主体内存活约 5–7 年，宿主死亡或老化时需更换。
- **原始态交流**：寄生体在原始态下通过接触彼此的纤毛进行「直接对话」，速度极快，人类无法理解。
- **母体的「农业思维」**：视人类为「牲口」——低阶眷属是工具，寄生体是管理者。长期战略：灭绝人类高层抵抗力量，圈养剩余人口作为宿体来源。
