# 世界观与设定总纲

> 寄生，从来不是占据身体，而是**夺走信任**。

---

## 一、核心理念

本书真正的敌人不是怪物，而是**怀疑**。

每一卷都围绕一种「信任」的瓦解与重建展开：

| 卷目 | 信任主题 | 核心悬念 |
|------|----------|----------|
| [[04-剧情大纲·六卷史诗#第一卷-感染前夜|第一卷：感染前夜]] | 相信自己看到的 | 你所见的一切，是否已被污染？ |
| [[04-剧情大纲·六卷史诗#第二卷-巢穴初显|第二卷：巢穴初显]] | 相信身边的人 | 当同伴可能被替换，你还能托付后背吗？ |
| [[04-剧情大纲·六卷史诗#第三卷-女王的面纱|第三卷：女王的面纱]] | 相信组织 | 庇护所的高墙内，领袖是否还是人类？ |
| [[04-剧情大纲·六卷史诗#第四卷-文明的重量|第四卷：文明的重量]] | 相信人类 | 面对更「高效」的文明，人类的坚守还有意义吗？ |
| [[04-剧情大纲·六卷史诗#第五卷-源祖之瞳|第五卷：源祖之瞳]] | 相信自己还是人 | 当界限模糊，你该如何定义自己？ |
| [[04-剧情大纲·六卷史诗#最终卷-抉择|最终卷：抉择]] | 信任 | 当你可以成为任何人，你选择成为谁？ |

**恐怖来源**：并非单纯的怪物追杀，而是「无人可信」的猜疑——你身边的任何人，都可能在下一秒变成敌人。

**末日本质**：这不是生存之战，而是两个物种对地球所有权的争夺。

**人类处境**：从食物链顶端跌落，被迫沦为猎物、宿主和原材料。

## 二、寄生文明：柯萨（Kosa）

它们不是病毒，而是一个名为**「柯萨」**的流浪文明。

### 2.1 文明本质

- **生物技术登峰造极**：整个种族就是一个巨大的、可分裂的蜂巢意识。
- **到来原因**：资源耗尽的星际**迁徙**，类似人类殖民。
- **眼中的人类**：占据新家园的「土著」。
- **行动逻辑**：不带仇恨，只有冰冷的**效率**。

### 2.2 社会结构

| 阶层 | 说明 |
|------|------|
| **源祖（The Origin）** | 远在星空深处的文明意识集合体，柯萨文明的「灵魂」。所有母体都是它的延伸，终极目标是降临地球，将其转化为新的永恒载体。详见 [[06-关键情节设计#源祖的真相]] |
| **七位「女王」（The Seven Mothers）** | 降落地球的七位母体，各具独立意识与战略风格，是源祖的「手指」。详见 §三 |
| **寄生体阶层** | 完整的文明承载者，拥有军队、科研人员、艺术家和历史记录者。详见 [[02-寄生体系详解#第二级-寄生体]] |
| **眷属生态** | 高度分化的生物工具，类似人类社会的机器和基础设施。详见 [[02-寄生体系详解#四、第三级：低阶眷属（普通丧尸/怪物）]] |

### 2.3 降临方式

陨石碎片坠入地球后，母体由碎片直接激活（或由多个始祖级寄生体融合而成），随后通过孢子云、地下水、眷属运输等方式投放「寄生体种子」，展开分层入侵。

## 三、七位「女王」：全球战略版图

七位母体拥有不同性格与战略，决定了全球各地的末日形态。

| 区域 | 代号 | 战略风格 | 区域形态 |
|------|------|----------|----------|
| 北欧 | **理性者** | 极端理性，将占领区治理得井井有条；冷酷精准，不浪费一兵一卒 | 秩序森严的「样板占领区」 |
| 亚洲 | **潜伏者** | 偏爱渗透与取代，几乎不制造大规模尸潮；利用人类社会内部矛盾，让城市从内部瓦解 | 表面正常、内里腐烂的城市 |
| 北美 | **将军** | 最具军事侵略性，创造种类繁多的重型战斗眷属 | 人类认知中最典型的「异形战争」 |
| 非洲 | **生物艺术家** | 痴迷基因改造 | 外星丛林：融合地球生物特征的异兽层出不穷 |
| 南美 | **建筑师** | 专注环境改造，菌毯生态系统最为壮观 | 整座城市数周内变成活体巢穴 |
| 大洋洲 | **收藏家** | 对人类文化表现出病态兴趣 | 可能保留着大量被圈养的、「生活幸福」的人类群落 |
| 南极 | **沉睡者** | 最古老、最庞大；深埋冰层之下，从未大规模活动 | 目的与能力完全未知（开放悬念） |

> **剧情价值**：七位女王的差异使全球各地呈现完全不同的末日形态，为后续可能的扩写（海外线、南极真相）留足空间。

## 四、四层蜂巢网络：永不遗忘的文明

柯萨文明的强大，根植于其独特的意识网络。这解释了为何人类难以用同一种方法击败它们两次。

| 层级 | 名称 | 范围 | 延迟 | 功能 |
|------|------|------|------|------|
| 第一层 | **低语（LAN）** | 5 公里内 | 即时 | 寄生体与眷属间战术配合，天衣无缝 |
| 第二层 | **共鸣（WAN）** | 数百公里（母体中继） | 分钟级 | 战略协调，类似互联网 |
| 第三层 | **传承（Memory Upload）** | 全母体范围 | 死亡时上传 | 寄生体死亡前，所有记忆与战斗经验上传母体——**经验永不消失**，人类很难用同一种方法击败它们两次 |
| 第四层 | **文明（Civilization Library）** | 跨星际 | 定期同步 | 所有母体与星空中的源祖同步数据，文明级知识共享——北美发现新武器，亚洲母体几小时后就知道 |

> **写作提示**：网络是柯萨文明的「神经系统」，也是人类科技树（[[03-人类阵营与科技树#四、人类科技发展的五个阶段]]）的破解目标。第三层「传承」是主角在[[06-关键情节设计#三、各卷核心反转]]中得知的核心弱点。

## 五、人类为什么无法分辨寄生体？

寄生体**不是模仿人类，它们在生理上就是人类**。

- 它们呼吸、流血、心跳、流汗，甚至可以在特定刺激下流泪。
- 它们利用的是宿主的完整生理系统。
- **唯一破绽**：体温恒定低于正常人 1.5–2℃；瞳孔在绝对黑暗中反射微弱荧光。
- 但这些特征都能被高明的寄生体有意识地控制与隐藏。

> **推论**：仅凭肉眼几乎无法识别，人类需要依赖科技手段（[[03-人类阵营与科技树#四、人类科技发展的五个阶段]]）与主角的异能（[[05-人物设计#二、主角能力体系：五阶进化]]）。

## 六、寄生体的人格：融合的双重灵魂

寄生体拥有完整人格，且人格由**寄生体本身与宿主大脑「融合」**而成，而非伪装：

- 寄生了一位钢琴家 → 对音乐保持病态的热爱。
- 侵蚀了一位警察 → 行事格外缜密，甚至保留正义感。
- 寄生了一位厨师 → 保留做饭习惯。

**最深的悲剧与最大伏笔**：

> 寄生越久，它越会怀疑——**自己到底是谁**。

这一设定是后期最大的剧情转折点与人物复杂度来源。详见 [[06-关键情节设计#五、寄生体的自我怀疑（后期大伏笔）]]。

## 七、源祖（The Origin）：真正的终局反派

- **不是**第一只寄生体，而是**整个文明的意识集合**。
- 母体只是它伸出的「手」。
- 源祖从未降临地球，一直在星空深处等待——如果所有母体完成任务，它才会真正到来。
- 它的真相（熵寂与「拯救」）见 [[06-关键情节设计#源祖的真相]]。

**第一部的收束**：母体死了，但星空深处，一个庞大的意识睁开了眼。它知道：地球出现了一个变量——那个半感染的人类。
