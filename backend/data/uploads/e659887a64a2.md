# 第四章 归途

巷口的风带着焦糊味。

我和林晓月贴着墙根走，走了十几步才敢放开腿。学校方向的声音被高墙挡在后面，变成一片嗡嗡的闷响。窄巷里没有人，只有两只流浪猫蹲在垃圾桶上，看见我们也不跑，歪着头，眼睛在阴影里泛着绿光。

「你手机还有电吗？」林晓月问。

有。我掏出来——信号两格，时断时续。她也在掏手机，我们一边走一边低头按屏幕。班级群炸了，消息一条接一条往上顶，全是「你们在哪」「三楼有人吐血了」「快跑」——没人说得清发生了什么。有人发了一条视频，封面是走廊，糊得看不清。我没点开。

「我妈……」林晓月的声音顿了一下，「打不通。」

「我爸也是。」我说，「可能线路忙。」

她没接话。我们继续走，谁都没再提电话的事。

走出巷子，就是正街。

街上的样子让我愣了一下——不是乱，是说不出的不对。下午四点多，太阳还挂着，街边的店有的开着门，灯亮着，柜台上没人；有的已经拉下卷帘门，卷帘门上贴着「停业」的白纸。有辆私家车横在路中间，车门开着，驾驶座上没人，发动机还响着，仪表盘的灯一闪一闪。街对面一个老太太拖着一只行李箱，正在往北走，走几步回头看一眼，像在等什么人。

没有太多人在跑。街上的人都是走——快步走，小跑，低着头，往各个方向散。没有尖叫声，只有脚步声、汽车喇叭声、远处时断时续的警笛声。安静得诡异，安静得像整个城市都在屏住呼吸。

林晓月的手一直在抖。

「陆沉，」她小声说，「我有点怕。」

「嗯。」我说，「我也是。」

我走在她外侧，把她往墙边让了让。我左手拎着书包，右手空着——我从路边捡了一根断掉的拖把杆，拆下拖布头，拎着那根杆子。杆子挺沉，木头，一头磨得发亮。我不知道这能干嘛，但手里有点东西，心里踏实一点。

手机又震了一下。最后一条能刷出来的新闻：

「多地爆发不明疫情，请市民居家避险，不要外出，不要聚集。疾控部门正在调查，请勿听信谣言。」

发信时间，十二分钟前。

我的手指悬在屏幕上，看了那行字很久。「不明疫情」「居家避险」——下午三点，我还坐在教室里，觉得赵磊只是中暑。三个小时，事情就变成了这样。

「你家还有多远？」林晓月问。

「前面那条街，拐进去，十五分钟。」我说，「我爸妈出差了，家里没人。」

她点了点头，没有问为什么不去她家。

拐过街角的时候，我看见了那家便利店。

绿灯便利店，我们小区门口的，开了七八年了。店门口的灯箱还亮着，卷帘门只拉起一半，里面灯光明晃晃的。玻璃门半开，一股冷气从里面飘出来。

我本来没打算停。但余光瞥见门口地上有个东西——一只白色的帆布鞋，孤零零一只，鞋带散着，躺在门槛边。

然后我看见了店员。

他穿着便利店的制服，蓝灰色马甲，戴着帽子，歪歪扭扭地从门里走出来。他走路的样子不对——脚后跟不落地，整个人往前倾，两只手臂垂着，像提线木偶。他走过门槛，停住，抬头。

他的脸很白。白得像被水泡过。他的嘴微张着，嘴角有一道暗红色的涎水，一直垂到下巴。

他看见了我。

他歪着头，朝我走过来。一开始是走，然后是挪，越来越快，喉咙里发出一阵「嗬嗬」的气音，像漏风的箱子。

「陆沉！」林晓月拽住我的胳膊，声音都变了调，「他、他——」

「别动。」我说，「别出声。」

我不知道我哪来的冷静。也许是下午看过太多了——王明跪在便池前吐内脏的画面还在我脑子里，一个脸色煞白的人朝我走过来，居然没有让我害怕到跑不动。我只是握紧了拖把杆，往后退了一步，让林晓月躲到我身后。

店员越来越近。五米，三米。

我举起拖把杆，朝他肩膀捅了过去。

杆子杵在他胸口，把他顶得一个趔趄，往后倒退两步。他没有叫，没有停，又朝前扑。我再捅，这一下戳在他下巴上，他脑袋往后仰，帽子飞了，露出额头上一条蜈蚣一样的青筋。

我看见他的眼睛。

瞳孔是散的，很大，大得不正常。像两口深井，什么都倒映不进去。

我转身，拉着林晓月就跑。

我们跑过便利店门口，跑过横在路中间的车，跑过那个还在发动机响着的空车。身后传来「嗬嗬」的声响和脚步声——不是跑，是那种歪歪扭扭、越追越近的脚步声。我回头看了一眼，他追了半条街，然后在一根电线杆旁停住，歪着头，看我们跑远，像忘了自己为什么要追。

我和林晓月一口气跑进小区门口。

小区的铁门开着，保安亭里没人，桌上还放着一只茶杯，茶还温着。我拉着她穿过花坛，跑到我家那栋楼下，才停下来，撑着膝盖喘气。肺像要烧起来，太阳穴一蹦一蹦地跳。

林晓月也喘得厉害，手扶着墙，脸色发白。她没哭，只是问：

「刚才那个……和学校里那些人，是一样的吗？」

「不知道。」我喘着气说，「可能。」

「他们……是人变的吗？」

我没回答。我想起王明，想起赵磊，想起医务室观察床上那具越来越安静的身体。我的喉咙发紧，什么话都说不出来。

楼下的防盗门关着。我掏钥匙，手抖得插了好几次才插进去。我们进了楼道，我把防盗门在身后关上，锁了两道。

楼道里很暗。光线从楼梯间的窗户透进来，一格一格的，灰尘在光柱里浮着。楼上很安静，偶尔传来一两声狗叫，又没了。

我们一层一层往上爬。到了四楼，我家门口。

我停下来，把手按在门把上，回头看了林晓月一眼。她站在我身后，刘海被汗黏在额头上，校服后背撕开的那道口子还在，露出里面白色的内衬。

「进来吧。」我说，「这就是我家。」
