## 1.`dropout`概率
---
- `dropout概率`是指在训练时神经网络会**随机按照一定比例——`dropout概率`来“丢弃”一部分神经元的输出**。其中丢弃指将一部分神经元的输出置为0，同时将保留的神经元输出放大`1/(1-p)`倍，以保证期望输出值不变。这迫使模型不依赖少数特定神经元，从而提升模型泛化性。
-  常见默认值为`0.1(小模型)`或`0.3(大模型)`
### 作用
- 防止**过拟合**
- 提高模型在新数据上的**泛化性**
- 只会在训练阶段（`model.train()`）生效，在推理/测试阶段（`model.eval()`）会关闭 
### nn.Dropout(...)
- 是`Pytorch`提供的一种**正则化层**，用于**防止过拟合**

## 2.前向传播、反向传播
---
	**前向传播（`Forward Propagation`）**: 数据从输入层开始，逐层计算，最中得到输出结果的过程。可以理解为 原始文本->BERT编码->`Dropout`->分类器->输出`logits`。每一层按照对应的权重、激活函数......来处理数据，最终产生预测值。
	**反向传播（`Backward Propagation`）**: 训练模型的关键步骤。当模型输出与只是标签出现误差（通过损失函数计算），该误差会从输出层向输入层 **反向** 逐层传播，同时计算每个**权重矩阵**中的参数**对误差的”**`贡献度`**“——“**`梯度`”。然后优化器（如SGD、Adam）利用这是梯度更新参数，使下一次前向传播的误差变小。如此反复迭代，最终实现逻辑回归。

## 3.`Python`相关容器结构
---
#### 列表（`list`）——最常用的可变序列
	写法：用方括号`[ ]`，里面的元素用逗号隔开
```python
numbers = [1,2,3,4]
words = ["hello", "the fucking world"]
mixed = [1,"two",3.0]
```
- 特点：
	**有序**：元素的顺序就是插入的顺序
	**可修改**
	**允许重复**
- 常用操作：
```python
numbers.append(5) #向末尾加一个元素
temp = numbers[0] #下标访问，同时也能用此方法修改对应元素值
```
#### 元组（`tuple`）——不可变序列
	写法：用圆括号`( )`,其中元素用逗号隔开
```python
point = (3,4)
info = "Alice",25
```
- 特点：
	**有序**：同列表
	**不可修改**：一旦创建就不能增、删或者修改
	**允许重复**
#### 字典（`dict`）——键值对集合
	写法：用花括号`{ }`，其中是 键：值 构成的结构
```python
person = {
  "name":"Alice",
  "age": 25,
  "city": "Shanghai"
}
```
- 特点：
	**键不能重复**
	**值可以修改且不限类型**
	**可修改**：可增、删、修改值
#### 集合（`set`）——不重复的无序结合
	写法：也用花括号 `{ }`，但里面不是键值对，只是单个元素。
	或者可以用 `set()` 创建空集合（注意 `{}` 是空字典，不是空集合）。
```python
fruits = {"apple","banana","orange"}
unique_letters = set("hello") #结果是{'h','e','l','o'}，重复的'l'只保留一个
```
- 特点：
	**无序**
	**不可重复**
	**可以修改**
## 4.Python相关语法
### `.view()`函数
	是Pytorch中改变张量形状的方法，不改变里面的数据，只改变数据的排列方式。
### (1). -1 的用法
```
z = x.view(-1, 2)  # 列数指定为2，行数自动算
print(z.shape)     # torch.Size([3, 2])
# 因为 6 / 2 = 3 行

w = x.view(2, -1)  # 行数指定为2，列数自动算
print(w.shape)     # torch.Size([2, 3])
```

## 5.归一化、标准化
	调整模型各个特征的比例，适当的突出某些特征
### 标准化方法
1.批标准化方法：`提高训练速度，稳定模型训练，增强泛化能力`
- 调整数据分布，减轻参数初始化的依赖，前向激活值与反向梯度更有效
- 可以使用更高的学习率，增强泛化性
- 平滑了优化目标函数曲面，梯度更稳定

	减少过拟合
