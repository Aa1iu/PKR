## 🔴 P0 致命

### 1. 不能创建知识库
- **页面**：`http://localhost:5173/zhishiku`
- **文件**：`pages/KBList.tsx:147-149`、`api/kbs.ts`
- **根因**："新建知识库"按钮无 onClick，API 层缺 `createKB()`
- **修复**：`api/kbs.ts` 加 `createKB` + `deleteKB`；`KBList.tsx` 加 Modal 表单

### 2. 不能删除/编辑知识库
- **文件**：`pages/KBList.tsx`、`api/kbs.ts`
- **根因**：UI 无删除/编辑按钮，API 层缺封装
- **修复**：`api/kbs.ts` 加 `deleteKB`/`updateKB`；表格加操作列

### 3. 图谱节点浮窗文档链接全坏
- **文件**：`api/graph.ts`、`components/KnowledgeGraph.tsx`、后端 `schemas/__init__.py`
- **根因**：后端 `doc_refs: string[]`，前端期望 `{doc_id, filename, page}[]`
- **修复**：改后端 Schema 为对象数组，或前端加转换函数

### 4. PDF/DOCX/PPTX 文档无原始排版渲染
- **文件**：`pages/DocReader.tsx`、后端 `routers/docs.py`
- **需求**：
  | PDF | `<iframe>` 浏览器内置渲染 | 需后端文件流端点 |
  | DOCX | mammoth.js 前端转 HTML | 需 `npm install mammoth` |
  | PPTX | 图片画廊分页（静态，无需动画） | 需后端 LibreOffice→PNG |
- **后端（C）**：新增 `GET .../docs/{id}/file` 文件流端点；实现 `GET .../docs/{id}/page-image`（PPT 转 PNG）
- **前端（B）**：`DocReader.tsx` 按类型切换渲染器

### 5. 对话历史侧边栏显示假的预置对话

### 7. 图谱页没有知识库选择器
- **文件**：`pages/GraphPage.tsx`
- **根因**：无 KB 切换 UI，只能通过侧边栏选
- **修复**：上图谱页加 KB 下拉选择器
