### 图层架构

```
App.tsx                    ← 路由 + 主题/背景 + FloatChat 全局浮窗
├── main.tsx              ← ReactDOM 入口 + BrowserRouter + StrictMode
├── index.css             ← CSS 自定义属性（主题变量） + body 全局重置
│
├── pages/                ← 页面级组件（路由出口）
│   ├── zhuye.tsx         ← 主页：三栏布局（左对话历史 + 中 ChatPanel + 右侧边栏）+ 文档拖拽上传
│   ├── KBList.tsx        ← 知识库管理页：表格展示 / 查看 / 新建 + 空态（EmptyState）+ 错误态（Result + 重试）
│   ├── KBDetail.tsx      ← 文档管理页：Upload 拖拽上传 + 表格 + 删除 + 阅读跳转 + 空态（EmptyState）+ 错误态（Result + 重试）
│   ├── DocReader.tsx     ← 文档阅读器：分页浏览 + 按类型选择渲染器 + 支持从图谱浮窗带 page 定位（state.page + scrollTo 顶部）
│   ├── GraphPage.tsx     ← 知识图谱页：D3 力导向图（8/4 基础渲染 + 8/5 着色/定大小/高亮）+ API/Mock 状态标识
│   └── NotFound.tsx      ← 404 页面：AntD Result status="404" + 返回首页按钮
│
├── components/           ← 可复用 UI 组件
│   ├── Sidebar.tsx       ← 右侧侧边栏容器：KB/Doc 列表切换 + 主题/背景图设置 Modal
│   ├── SidebarKBList.tsx ← 侧边栏知识库列表（缩略视图）
│   ├── SidebarDocList.tsx ← 侧边栏文档列表（缩略视图 + 拖拽上传）
│   ├── ChatPanel.tsx     ← 主页内嵌对话面板：消息列表 + 底部输入栏
│   ├── ChatHistorySidebar.tsx ← 左侧对话历史侧边栏：会话列表 + 新建/切换/删除（镜像右侧 Sidebar 按钮条模式）
│   ├── FloatChat.tsx     ← 全局浮动对话窗口：Portal 渲染 + 可拖拽 + 最小化

│   ├── SourceCitation.tsx ← 来源引用标签：AI 回复底部展示引用的文档/页码/相关度（Tooltip 预览片段）
│   ├── PdfPageRenderer.tsx ← 纯文本分页渲染器（PyMuPDF / python-docx 提取文本）
│   ├── EmptyState.tsx      ← 空态占位组件：自定义 SVG 插图（圆形底 + 文档图标 + 加号徽章）+ 主题自适应，支持 kb/doc 两种类型
│   └── KnowledgeGraph.tsx ← D3 力导向图：8/4 基础渲染 + 8/5 着色（图例）/定大小/高亮 + 8/6 缩放/平移/拖拽 + 8/7 点击浮窗 + 8/8 浮窗文档跳转 + 8/9 加载动画（渐显+overlay，Phase 3）

├── hooks/                ← 自定义 Hooks
│   └── useChatStream.ts  ← 流式对话钩子：创建消息 → 逐 token 追加 → done 收尾（ChatPanel + FloatChat 共享）
│
├── stores/               ← Zustand 全局状态
│   ├── themeStore.ts     ← 主题模式（light/dark）+ 背景图 URL，localStorage 持久化
│   ├── kbStore.ts        ← 知识库列表 + 当前选中 kb_id
│   ├── chatStore.ts      ← 多会话管理（Conversation CRUD）+ 消息流式追加 + 发送中状态（ChatPanel/FloatChat/ChatHistorySidebar 共享）
│   └── graphStore.ts     ← 图谱数据 + 加载/错误状态：fetchGraph（API 优先，失败 → error；空 → Mock 兜底）
│
├── api/                  ← 后端 API 封装层
│   ├── client.ts         ← 统一 fetch 封装（request / uploadRequest）+ ApiError 类
│   ├── kbs.ts            ← GET /api/kbs（知识库列表）
│   ├── documents.ts      ← GET/DELETE /api/kbs/{id}/docs + POST 上传（FormData）
│   ├── chat.ts           ← SSE 流式对话：streamChat（fetch+ReadableStream）+ mockStreamChat（开发用）
│   ├── graph.ts          ← GET /api/kbs/{id}/graph（图谱）+ MOCK_GRAPH 内联兜底数据
│   └── index.ts          ← API 层统一导出
│
├── types/
│   └── index.ts          ← 全局 TS 类型：KB, Doc, GraphNode, GraphEdge, ChatMessage, Conversation, ChatEvent
│
└── utils/

```

### CSS 主题变量体系

所有组件通过 `var(--color-xxx)` 引用 [index.css](frontend/src/index.css) 中的 CSS 自定义属性，根元素 `data-theme` 属性控制亮/暗切换：

- `--color-bg` — 页面背景，`--color-surface` / `--color-surface-secondary` — 卡片/容器背景
- `--color-border` / `--color-border-secondary` — 边框
- `--color-text` / `--color-text-secondary` — 文字
- `--color-primary` / `--color-primary-bg` / `--color-primary-shadow` — 主题色
- `--color-code-bg` / `--color-code-text` / `--color-code-inline` — 代码块
- `--color-blockquote-text` — 引用块文字，`--color-shadow` — 阴影，`--color-warning` — 警告色

### 对话流式链路

```
useChatStream.send(question)
  → chatStore.addMessage(user)
  → chatStore.addMessage(assistant 空占位)
  → for await (mockStreamChat / streamChat)
       → token  → chatStore.appendToken(msgId, token)
       → source → chatStore.finishMessage(msgId, sources)
       → done   → chatStore.finishMessage(msgId, sources, follow_up) + sending=false
       → error  → message.error() + sending=false
```

> 切换真实 API：修改 [useChatStream.ts](frontend/src/hooks/useChatStream.ts) 第 4 行 import，将 `mockStreamChat` 替换为 `streamChat`。
