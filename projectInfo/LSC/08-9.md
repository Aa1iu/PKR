## 【21:40】问题排查 — 前端 npm install 权限错误

### 问题

`npm install` 报 EPERM，node_modules 目录被锁定。

### 解决

```powershell
npm cache clean --force
Remove-Item -Recurse -Force node_modules
npm install  # 成功安装 419 packages
```

原因：VS Code 或其他进程占用 node_modules 文件。
