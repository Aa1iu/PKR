## 【17:30】执行修改 — P0 阶段修复（4 项）

### 三阶段流程

按用户要求的三阶段流程执行：分析排序 → 等待确认 → 逐项修复+四重自检（语法/逻辑/边界/运行测试）。

### P0-1：补 `/file` 端点

- `docs.py` 新增 `GET /{doc_id}/file` 路由 + MIME 映射表，返回 `FileResponse`
- 验证：DOCX→200+正确MIME、PDF→application/pdf、MD→text/markdown、不存在→404

### P0-2：`page-image` 降级实现

- 501 → 返回源文件流（`application/octet-stream`），清理未用 import
- 验证：200 + octet-stream

### P0-3：上传后自动触发图谱分析

- `_process_document_background` 成功后启动 `run_analysis`（`threading.Thread + asyncio.run`）
- **修复过程发现 2 个问题**：
  1. 相对导入路径写错（`.graph_analyzer` → `..services.graph_analyzer`）
  2. BackgroundTasks 线程无 event loop，`ensure_future` 会崩 → 改用独立线程
- 验证：上传→自动分析→**10 nodes + 8 edges**（概念质量高：RGB灰度转换、NEON SIMD指令集等）

### P0-4：对话历史持久化

- `chat.py` 从内存 dict → **ChatMessage 表**（`_add_message` 写表、`_get_history` 读表、DELETE 清表）
- SSE 期间用独立 session（避免请求 session 关闭）
- 验证：写入→查询→**重启后仍在**

### 附带修复：Embedding 离线模式

- `embedding_service.py` 顶部加 `HF_HUB_OFFLINE=1` + `HF_ENDPOINT=hf-mirror.com`
- 原因：模型已缓存但每次对话都尝试连 huggingface.co 超时 10 秒
