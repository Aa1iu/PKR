2. **3 种 Prompt 模板**：

   - global: 学习导航（知识库推荐）
3. **SSE source 事件**：先于 token 发送，告知前端检索来源
4. **SSE error 事件**：LLM 异常时发送 error 而非 token
5. **message_id**：每条消息生成唯一 ID
6. **内存对话历史**：按 kb_id 隔离存储，每个 KB 最多 40 条
